# פורמט ייבוא רווחית — ממתין למידע

מסמך זה יתמלא ברגע שנקבל דוגמת קובץ אמיתי מרווחית (ייצוא מלאי קיים, או
תבנית ייבוא). דברים שצריך למפות ברגע שהקובץ יגיע:

- שמות העמודות המדויקים שרווחית מצפה להן, ובאיזה סדר.
- מזהה הפריט: האם רווחית משתמשת במק"ט של היצרן (`Item`), בברקוד, או
  שיש לה מק"ט פנימי משלה שצריך למפות/ליצור?
- האם צבע+מידה הם שדות נפרדים בשורה אחת, או שרווחית מצפה לפריט "אב"
  (מוצר) עם וריאציות (מידה/צבע) כפריטי בת נפרדים בקובץ?
- פורמט המחיר: מטבע (USD מול ILS), האם צריך להמיר שער, כולל/לא כולל מע"מ,
  מחיר קמעונאי מול מחיר עלות/סיטונאי.
- קידוד הקובץ (rivhit ישנות לעיתים מצפות ל-Windows-1255 / CSV ולא UTF-8),
  וסיומת (.xlsx / .csv).
- האם ייבוא פריט חדש שלא קיים עדיין ברווחית דורש שדות חובה נוספים
  (קטגוריה, ספק, מיקום מחסן וכו') שלא קיימים בקובץ היצרן ואבא יצטרך
  להשלים אותם באפליקציה.
